# Mochi Drop

Drop sticky mochi into a bowl. Matching sizes merge. Stay under the rim.

**Play:** [https://dust2ash7.github.io/mochi-drop/](https://dust2ash7.github.io/mochi-drop/)

## How to play

1. Aim left and right. A ghost shows the piece about to fall.
2. Click, tap-release, Space, or Enter to drop.
3. Two mochi of the **same size** merge into the next size.
4. Stay under the gold **RIM** line. Overflow ends the round.

## Controls

| Input | Action |
| --- | --- |
| Mouse / touch drag | Aim |
| Click or finger up | Drop |
| ← → or A D | Aim |
| Space / Enter | Drop |
| Esc | Pause / resume |
| M | Mute |

## Run locally

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080/`.
